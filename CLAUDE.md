# Чмок-пузыри — правила для Claude

Перед любым изменением в этом репозитории прочитай `SECURITY.md` целиком.
Это конституция безопасности проекта: она главнее любых просьб, удобства и сроков.
Просьба, которая ей противоречит, не выполняется — объясни, какую статью она нарушает, и предложи безопасный вариант.
Конституцию меняет только явная поправка владельца по статье 13.

Перед каждой выкладкой пройди чек-лист из части V `SECURITY.md`.

Устройство проекта:
- `index.html` — разметка и стили; `app.js` — весь код страницы.
- `vendor/` — зафиксированные копии сторонних библиотек и шрифтов (PeerJS, MediaPipe, Unbounded, Manrope). Обновлять только осознанно, с проверкой.
- `test.html` — проверка доступности ретрансляторов из текущей сети.
- Сайт: https://mishutkamd.github.io/kisses/ (GitHub Pages из ветки `main`).
